# Estadis — investigación y validación histórica de Kino Chile

Este repositorio conserva la investigación, las evidencias, los Work Items y la gobernanza del proyecto Estadis. **GitHub es la memoria persistente**: los nuevos chats deben recuperar el estado real de Issues, PRs, decisiones y SHA antes de trabajar.

## Separación de responsabilidades

**Estadis investiga y documenta su propio producto.** El Supervisor asigna y revisa; el Implementador ejecuta dentro del Work Item; GitHub persiste estado y evidencia. **Actuador es un transportador externo de mensajes entre chats**, con Supervisor propio: **nadie de Estadis puede modificarlo, controlarlo, ejecutarlo, depurarlo, desplegarlo ni gestionar su repositorio o su runtime**.

Supervisor e Implementador sólo publican sus mensajes normales en **GitHub de Estadis**, identificando rol, Work Item, autoridad, PR, HEAD y estado. No se requiere ni se autoriza modificar Actuador para transportarlos.

## Estado de producto

Las tareas de adquisición histórica, validación y las investigaciones futuras se rigen por sus Issues y decisiones actuales. La presencia de datos, documentos o PRs abiertos no implica por sí sola validación oficial ni autorización para análisis estadístico/modelos. Consultar los [Issues vigentes](https://github.com/cmiloarevalo-hash/Estadis/issues) y [PRs](https://github.com/cmiloarevalo-hash/Estadis/pulls) antes de iniciar una actividad.
